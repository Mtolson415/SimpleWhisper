# Design, component, template and model reference library

Reviewed November 11, 2026. This is a broad, categorized library rather than a literal inventory of the entire internet. Links go to the providers themselves. Some sites block automated browsing or require an account; inclusion does not imply unrestricted access, a free plan, or permission to copy assets. Check the particular item's license before reusing code, fonts, images or models.

For AI-assisted coding, choose a few references and describe exactly what to borrow: layout, spacing, typography, palette, controls and motion. A screenshot is visual guidance, not a complete implementation specification. Web component code is not directly compatible with this Python/Tk desktop app; its visual ideas can still guide a desktop redesign.

## Start here

For this dictation utility: Mobbin for practical app screens, Fluent for Windows patterns, CustomTkinter/ttkbootstrap for implementable Python controls, and Lucide for a consistent icon family. For a website: Landbook/Lapa for layouts, 21st/shadcn for components, tweakcn for themes, and Realtime Colors for color experiments.

## Turn references into a usable brief

For a redesign, record: the target screen, two or three reference links, which parts you like, your preferred light/dark palette, typography, spacing, keyboard behavior and accessibility needs. Ask the coding agent to preserve model endpoints, recording behavior and tests while changing presentation. Start with a mockup before replacing the working interface.

For this app, a useful direction is a compact recorder: visible listening state, one prominent microphone control, clear model/input selection, grouped continuous/auto-stop settings, and a transcript area with clear provisional-versus-final text. Excessive animation and decorative effects would compete with the task.

## Link-check limits

Provider pages were consulted during research. Some block automated fetches, use JavaScript-only pages or redirect. In particular, Godly redirects to Recent Design. Pages such as Page Flows, Screenlane, Coolors, Color Hunt, Blush, Sketchfab and SVG Backgrounds may need normal interactive browsing. No live pricing, per-item licensing, account access or compatibility audit is claimed.
