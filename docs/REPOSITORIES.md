# Repository pair and shared work

- Public: https://github.com/Mtolson415/SimpleWhisper — portable tool, Docker runtime, source, tests and portfolio documentation.
- Private: https://github.com/Mtolson415/z13-ai-workspace-private — deployment source, machine-specific operating notes, synthetic migration evidence and current cross-agent handoff.

Standing user rule: completed project work is reflected in both records. Reusable changes go public; sensitive work gets a safe public summary and appropriate private detail. Never publish secrets, raw conversations, recordings, model weights or private databases, even in the private repository. Keep the map and handoff current; verify pushes/checks before claiming synchronization.

ChatGPT, Claude and local coding agents must pull current state and read AGENTS.md/CLAUDE.md and the private HANDOFF.md. Use branches to avoid overlapping writes. GitHub does not automatically share chat history, unsaved work or model memory. Each agent needs its own authorized access. Local GitHub Desktop copies may synchronize once daily; hosted commits/pushes happen at completed milestones.
