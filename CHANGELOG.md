# Changelog

## 0.5.3 — source/local build

- Added a dark, responsive startup checklist with real service readiness, visible failure details and automatic dismissal when the toolbar responds.
- Desktop launcher can start Docker Desktop and containers; its script policy is scoped to the launcher process.
- Refined microphone, independent On top toggle and settings artwork with smooth edges and hover feedback.
- Removed pause ellipses from dictation without joining adjacent words.
- Documented host, Docker, microphone, storage and source-development requirements.

## 0.5.2 — 2026-11-12

- SimpleWhisper app, executable and shortcut name; feather icon retained.
- Matching dark title bars, fields and dropdowns.
- Microphone button controls listening; independent **On top** switch controls pinning.
- Configurable shortcut with conflict preservation and suspension during Settings.
- Illustrated project page, expandable guides, downloads and community policies.
- Owner reports tested and working; detailed compatibility coverage remains limited.

## 0.5.1 — 2026-11-12

- Verified owned-container shutdown and forced-owner-termination helper.
- Retired Startup watcher; unrelated services preserved.

## 0.5.0 — 2026-11-12

- Simplified direct-dictation toolbar without automatic listening timeout.
- Removed transcript-panel, manual-copy, rolling-revision and background-lock workflows.
- Worker phrase detection, native focus protection and bounded queues.

## Earlier versions

[v0.2.0](https://github.com/Mtolson415/local-whisper-dictation/releases/tag/v0.2.0) introduced hosted portable downloads. Versions 0.3/0.4 explored superseded interfaces. Git history and [archived notes](docs/RELEASE-ARCHIVE.md) preserve evidence; historical behavior is not current setup guidance.
